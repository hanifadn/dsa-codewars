## File format and local runs

### File headers

Each `.rb` file begins with line comments (`#`): title, link to the kata on Codewars, difficulty, and problem description.

Solutions are grouped in subfolders named after Codewars difficulty (for example `8kyu/`). Folder names match the level so you can navigate by kyu.

### Running locally

**To run a solution on your machine:**

- **Tech stack:** [Ruby](https://www.ruby-lang.org/) — standard library (no extra gems required for these exercises).
- **Ruby:** **2.7** or newer (Ruby **3.x** recommended).

Check your runtime: `ruby --version`

```bash
ruby path/to/kata-file.rb
```

If the file only defines methods, use `irb` and `load "path/to/kata-file.rb"`, or paste the code into the Codewars editor and run tests there.
