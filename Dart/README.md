## File format and local runs

### File headers

Each `.dart` file begins with line doc comments (`///`): title, link to the kata on Codewars, difficulty, and problem description.

Solutions are grouped in subfolders named after Codewars difficulty (for example `8kyu/`). Folder names match the level so you can navigate by kyu.

### Running locally

**To run a solution on your machine:**

- **Tech stack:** [Dart SDK](https://dart.dev/) — standard library (no extra packages required for these exercises).
- **Dart:** **2.19** or newer.

Check your runtime: `dart --version`

Snippets define top-level functions only (no `main`). To run locally, add a temporary `main`, or paste the code into the Codewars editor and run tests there.

```bash
dart path/to/kata-file.dart
```
